# Interview_Prep_JavaTech

Interview preparation notes for senior Java backend roles — Spring Boot, Hibernate, Kafka, Docker, system design, and Java version migration.

## Contents

- `DAY01/`
  - `SpringBoot Hibernate Apps.md` — How to present a Spring Boot/Hibernate project to an interview panel (three presentation structures)
  - `System Architecture.md` — System architecture Q&A
  - `All 3 Q&A.md` — Consolidated Q&A
  - `Prompt Gemin.md` — Prompting notes
- `DAY02/`
  - `HelloWorld_SpringBootApp.md` — Minimal Spring Boot app walkthrough
- `DAY03/`
  - `SpringBoot_MicroServices_Challenges.md` — Common microservices challenges and how to discuss them
- `Java 8 to Java 17+ Migration.md` — Key changes and migration considerations from Java 8 to 17+
- `Real Bank Application Feature/` — End-to-end feature spec: monthly bank statements in PDF/CSV (Java 21, Spring Boot, PostgreSQL, AWS S3) — a realistic system-design exercise

## How to use

Day-by-day notes plus a feature spec you can whiteboard. The bank-statement feature is a good mock system-design prompt: requirements, tech choices, and trade-offs.
